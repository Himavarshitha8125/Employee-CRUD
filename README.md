# Employee CRUD Application

## Tech Stack
- Java
- Spring Boot
- MySQL
- JPA / Hibernate

## Features
- Create Employee
- Get All Employees
- Update Employee
- Delete Employee

## API Endpoints
POST /employees
GET /employees
PUT /employees/{id}
DELETE /employees/{id}

## How to Run
1. Clone repo
2. Configure MySQL in application.properties
3. Run Spring Boot application
